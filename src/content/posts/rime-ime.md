[Rime/中州韵输入法引擎](https://rime.im/) 是一款跨平台的输入法算法框架。

我使用 Rime 输入法也已经有1年多了，便决定写一篇文章记录我的使用经历和感受了。

## 使用原因

我第一次接触到 Rime 输入法是在一年前刷B站时刷到的，那时我才刚开始学习双拼，对输入法的了解还仅限于搜狗输入法。:spoiler[（不得不说搜狗广告是真多）]

我被视频中介绍的无广告、高自定义度吸引了，立刻就准备下载下来试试。

## 下载安装

Rime 只是一个输入法引擎，他在不同平台有不同的应用。比如 Windows 端是小狼毫，macOS 端是鼠须管，有些系统甚至有多个应用。

先打开[下载页面](https://rime.im/download/)，然后根据自己的系统选择对应的版本，目前支持 Windows、macOS、Linux、Android。

然后下载即可。因为是从 GitHub 下载的，国内访问可能不是那么顺畅。可以使用 [Watt Toolkit](https://steampp.net/) 加速访问，并使用多线程下载器（如 [AB Download Manager](https://abdownloadmanager.com/#download)）下载。

下载完成后双击打开，安装。按照提示设置语言等。完成后切换到 Rime 输入法，按 Ctrl+` 或 F4 打开方案选单，选择“朙月拼音·简化字”。

另外，还可以在设置>时间和语言>输入>高级键盘设置>替代默认输入法（Windows 11）或设置>时间和语言>语言>相关设置>高级键盘设置>替代默认输入法（Windows 10）将小狼毫设为默认输入法。

然后就可以开始打字了。

## 初步探索

输入法内置的朙(míng)月拼音输入方案功能确实有些功能欠缺，我们可以在 GitHub 上查找别人配置好的输入方案。

第1个搜到的，毫无疑问，就是目前 Star 最多的[**雾凇拼音**](https://github.com/iDvel/rime-ice)。

::github{repo="iDvel/rime-ice"}

先打开雾凇拼音的[仓库链接](https://github.com/iDvel/rime-ice)，到右侧的“Releases”页面选择最新版本下载压缩包。如果没有则点击右上角的“Code”，然后选择“Download Zip”。

下载下来的压缩包解压。右键任务栏输入法图标（㞢）旁的“中”，选择用户文件夹，将压缩包里所有文件复制到打开的文件夹，如有重复的文件覆盖即可。

然后再次右键“中”，选择重新部署。Rime 每次修改配置都要重新部署才能生效。

这款配置方案的功能已经足够满足日常使用。相比于朙月拼音，雾凇拼音更改了皮肤样式，支持双拼，还拥有更好的词库和 Emoji 输入、中英混打、计算器等多项功能。我也使用了这套方案很长时间。

后来随着搜索的深入，开始使用雾凇拼音的一个分支——[**白霜拼音**](https://github.com/gaboolic/rime-frost)。

::github{repo="gaboolic/rime-frost"}

白霜拼音的词库比雾凇拼音更加准确，但除此之外就没有太大变化了。这个方案应该算是我使用时间比较长的了。

之后又切换到了另一个配置方案：[**薄荷输入法**](https://github.com/Mintimate/oh-my-rime)

::github{repo="Mintimate/oh-my-rime"}

当时使用这套方案主要是比较新奇，而且它的皮肤也不错。

我最后还是换回了白霜拼音。

## 辅助码

一次刷B站时了解到了小鹤音形，但在学习的过程中觉得小鹤音形太过于难以学习——不打完整的形码，就只有三四个候选项。:spoiler[（用习惯了其实也没那么难）]我便开始研究辅助码。

正因此，我从白霜拼音换到了同作者制作的[**墨奇音形**](https://github.com/gaboolic/rime-shuangpin-fuzhuma)

::github{repo="gaboolic/rime-shuangpin-fuzhuma"}

中途也因不习惯换回过白霜拼音，但最后还是长期稳定在了墨奇音形。

但墨奇音形这个方案竟然没有中英混输，十分影响日常使用。

我也尝试过缝合其他配置方案的中英混输，但过于麻烦和耗时，每次更新都要重新缝合。

## 万象拼音

我现在正在使用另一个方案——[**万象拼音**](https://github.com/amzxyz/rime-wanxiang)

::github{repo="amzxyz/rime-wanxiang"}

这套方案不仅拥有 Rime 生态最全面的词库和 lua 脚本，还能搭配作者训练的语法模型大幅提升长句输入准确率。这已经超越了大厂输入法关闭云拼音的输入准确率。

我之前一直没有使用一是没有发现，二是用习惯了墨奇音形。

这套方案还有标准版和增强（辅助码）版，能完全满足日常使用需求。

## 总结

这几个方案中，雾凇拼音是较早出现的，白霜拼音是基于其的优化，薄荷输入法最突出的特点则是皮肤。万象拼音是最晚出现的，也是功能最全的。

而就辅助码方面，万象拼音拥有更加丰富的双拼+辅助码组合，功能也更多。

词库方面，根据最新的数据，雾凇拼音<大厂输入法(关闭云拼音)<白霜拼音=墨奇音形<万象拼音=薄荷输入法(新版本)。

选择还是要看自己的喜好，建议都用用。

## 感受

使用 Rime 输入法一年下来的感受就是确实做到了**纯净无广告**和**高自定义程度**。

在输入法连候选项都要插入广告的当下，或许只有开源软件能做到让你不被广告打扰。

高自定义程度意味着你能把输入法打造成你想要的任何模样。无论想要什么输入法、什么功能，都能够在 Rime 中实现。向辅助码这种功能更是大厂输入法无法做到的，只能通过 Rime 来定制。

另外，说个题外话。如果你只想要纯净无广告的特点的话，可以试试[微信输入法](https://z.weixin.qq.com/web/)。

总之，Rime 没有大厂输入法臃肿的皮肤和广告，而是为了做好一件事——**重新让你感受到打字的乐趣**。
